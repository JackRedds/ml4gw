ml4gw.plotting.skymap

Mollweide plots of HEALPix sky localizations, e.g. from the FITS sky maps written by AMPLFI or HyperWave. Only uses matplotlib's built-in "mollweide" projection, so neither ligo.skymap nor healpy are required.

Plots are drawn onto a caller-provided axis when one is given, so that styling is left to the caller and several sky maps can be overlaid, e.g. to compare two pipelines:

fig = plt.figure()
ax = fig.add_subplot(projection="mollweide")
plot_skymap("amplfi.fits", ax=ax, label="AMPLFI")
plot_skymap(
    "hyperwave.fits", ax=ax, shade=False,
    contour_color="tab:orange", label="HyperWave",
)
ax.legend()

ml4gw.plotting.skymap.plot_skymap(skymap, ax=None, contours=(0.5, 0.9), true_ra=None, true_dec=None, shade=True, cmap='Blues', colorbar=True, contour_color='black', contour_labels=False, label=None, center_ra=3.141592653589793, flip_ra=True, resolution=(720, 360))

Plot a sky localization on a Mollweide projection.

Parameters:

  • skymap (SkyMap | str | Path) -- The sky map to plot, or the path to a FITS file to read it from

  • ax (Axes | None) -- Axis with projection="mollweide" to plot on. If None, a new figure and axis are created.

  • contours (Sequence[float]) -- Credible levels at which to draw contours. Pass () to draw none.

  • true_ra (float | None) -- Right ascension in radians of the true source location, which is marked with a star if given

  • true_dec (float | None) -- Declination in radians of the true source location

  • shade (bool) -- Whether to shade the probability density. Set to False when overlaying contours on a sky map that has already been plotted.

  • cmap (str) -- Colormap for the probability density

  • colorbar (bool) -- Whether to draw a colorbar for the shading

  • contour_color (str) -- Color of the credible region contours

  • contour_labels (bool) -- Whether to label contours with their level

  • label (str | None) -- Legend label for the contours. Pass this when overlaying several sky maps on one axis, then call ax.legend().

  • center_ra (float) -- Right ascension in radians at the center of the plot. Defaults to 12h, matching ligo.skymap.

  • flip_ra (bool) -- If True, right ascension increases to the left (East-left), the usual astronomical convention

  • resolution (tuple[int, int]) -- Number of (longitude, latitude) grid points the sky map is evaluated at for plotting

Return type:

Axes

Returns:

The axis the sky map was drawn on
