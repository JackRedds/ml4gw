ml4gw.skymap

A lightweight container for HEALPix sky localizations, with a reader for the FITS sky maps written by ligo.skymap (and so by AMPLFI), healpy, or any other package following the LIGO/Virgo/KAGRA sky map format.

Both multi-order (ORDERING = NUNIQ) and flat (ORDERING = NESTED or RING) maps are supported. Only numpy and astropy are required; neither healpy nor ligo.skymap are needed.
